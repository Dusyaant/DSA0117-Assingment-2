This repository contains the second set of C++ programs for the **DSA0117** course. These 10 programs focus on advanced control structures, mathematical modeling, and foundational data handling techniques.

## 📂 Included Programs

1.  **N-th Fibonacci Number (Ladder Logic):** Calculates the Fibonacci sequence up to index $N$ using an `if-else-if` ladder for base cases and iterative calculation.
2.  **Perfect Number Checker (FOR Loop):** Determines if a number is perfect (sum of proper divisors equals the number) using a `for` loop.
3.  **Perfect Number Checker (WHILE Loop):** The same logic as above, implemented using a `while` loop to demonstrate loop equivalence.
4.  **Natural Number Summation (FOR Loop):** Computes the sum of the first $n$ natural numbers using a `for` loop.
5.  **Natural Number Summation (WHILE Loop):** Computes the sum of the first $n$ natural numbers using a `while` loop.
6.  **Natural Number Summation (DO-WHILE Loop):** Computes the sum of the first $n$ natural numbers using a `do-while` loop, ensuring at least one execution.
7.  **Power Function:** A mathematical utility to calculate $Base^{Exponent}$ for both positive and negative exponents.
8.  **Smallest Missing Element:** An algorithm to find the smallest missing non-negative integer in a sorted array.
9.  **Most Frequent Element:** Analyzes an array to find the "mode" or the element with the highest frequency of occurrence.
10. **Bitwise 'Set Bit' Operation:** Demonstrates low-level data manipulation by setting the $N$-th bit of a given integer using bitwise OR and shifting.
